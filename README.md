This project is a smart recycling platform that helps users, business owners, and administrators manage aluminum scrap and reusable items digitally.
It includes features like pickup scheduling, item selling, wallet payments, chatbot support, admin control panel, and map-based tracking.
It is developed as part of a Final Year Project to address environmental waste challenges using digital tools.

 Features

-  User registration & login with role-based access (User, Business Owner, Admin)
-  Scrap pickup booking system with area, date & time selection
-  Reusable item listing for buy/sell
-  Scrap value calculation and wallet system
-  Map integration to show pickup areas and user location
-  Admin dashboard with charts, booking data, and user management
-  Chatbot for quick assistance
-  Email notifications for confirmation and support


Tech Stack

Frontend: React.js, Tailwind CSS, React Router  
Backend: Node.js, Express.js  
Database: MongoDB with Mongoose  
Authentication: JWT, Bcrypt  
Other Tools:  
- Multer (for image upload)  
- Google Maps API (location tracking)  
- EmailJS / Nodemailer (email service)  
- Jest, SuperTest, Enzyme (for testing)
